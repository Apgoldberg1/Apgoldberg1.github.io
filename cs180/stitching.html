Homography Estimation Using Least Squares

Problem

A homography is a 3×3 matrix H that relates corresponding points between two images through the equation:

H x = x'

Where x = [x, y, 1]ᵀ and x' = [x', y', 1]ᵀ are homogeneous coordinates of corresponding points which we get through our click interface.

System of Equations

For each correspondence pair (x, y), (x', y'), we can write two linear equations:

h₁₁x + h₁₂y + h₁₃ - h₃₁xx' - h₃₂yx' = x'

h₂₁x + h₂₂y + h₂₃ - h₃₁xy' - h₃₂yy' = y'

Matrix Form

This creates a system of equations Ah = b where:

A is a 2n×8 matrix (n = number of correspondences)

h = [h₁₁, h₁₂, h₁₃, h₂₁, h₂₂, h₂₃, h₃₁, h₃₂]ᵀ (8 unknowns)

b contains the target coordinates [x₁', y₁', x₂', y₂', ...]ᵀ

Least Squares Solution

We solve for h using least squares:

h = (AᵀA)⁻¹Aᵀb

The final homography matrix is constructed as:

H = [h₁₁ h₁₂ h₁₃]

       [h₂₁ h₂₂ h₂₃]

       [h₃₁ h₃₂ 1.0]

Interpolation Method Comparison

Performance: Bilinear interpolation takes longer than a nearest neighbor because the implementation requires copying shifts of the data and taking a weighted sum, but it's not excessively more expensive.

Visual Quality: When looking closely at the football field, especially the 10 yard line, the nearest neighbor version appears more jagged while bilinear interpolation helps to provide some smoothing, resulting in a more natural appearance.

Image Mosaics

Image Stitching Process

Homography Computation and Projection

I use the labelled correspondences to compute a homography matrix that relates the coordinate systems of the two images. Once the homography is determined, I project the corners of the image I'm warping to find what the resulting size should be for the output mosaic.

Pixel Mapping and Interpolation

For each pixel coordinate in the output image, I use the inverse transform to find the corresponding location in the original image. This allows me to sample the appropriate pixel value using either nearest neighbor or bilinear interpolation from the source image.

Alpha Blending

To blend the images smoothly, I added a linear alpha mask before projection. These alpha values are only used where the two projected images overlap to smooth the blending between them.

Blending Artifacts and Limitations

In some cases, this blending approach still leaves artifacts. One failure case occurs where two image corners are in a similar place, as seen in the sky of the first mosaic. The alpha values in both sections are low, so the skies are blended evenly. However, when the first image ends, there is a sudden shift to the unblended region. This would be less apparent if the images had more overlap where the corners landed in higher alpha regions of the other images.
