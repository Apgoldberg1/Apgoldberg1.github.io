Homography Estimation Using Least Squares

Problem

A homography is a 3×3 matrix H that relates corresponding points between two images through the equation:

H x = x'

Where x = [x, y, 1]ᵀ and x' = [x', y', 1]ᵀ are homogeneous coordinates of corresponding points which we get through our click interface.

System of Equations

For each correspondence pair (x, y), (x', y'), we can write two linear equations:

h₁₁x + h₁₂y + h₁₃ - h₃₁xx' - h₃₂yx' = x'

h₂₁x + h₂₂y + h₂₃ - h₃₁xy' - h₃₂yy' = y'

Matrix Form

This creates a system of equations Ah = b where:

A is a 2n×8 matrix (n = number of correspondences)

h = [h₁₁, h₁₂, h₁₃, h₂₁, h₂₂, h₂₃, h₃₁, h₃₂]ᵀ (8 unknowns)

b contains the target coordinates [x₁', y₁', x₂', y₂', ...]ᵀ

Least Squares Solution

We solve for h using least squares:

h = (AᵀA)⁻¹Aᵀb

The final homography matrix is constructed as:

H = [h₁₁ h₁₂ h₁₃]

       [h₂₁ h₂₂ h₂₃]

       [h₃₁ h₃₂ 1.0]

Interpolation Method Comparison

Performance: Bilinear interpolation takes longer than a nearest neighbor because the implementation requires copying shifts of the data and taking a weighted sum, but it's not excessively more expensive.

Visual Quality: When looking closely at the football field, especially in the bottom left corner, the nearest neighbor version appears more jagged while bilinear interpolation helps to provide some smoothing, resulting in a more natural appearance.
